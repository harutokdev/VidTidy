# 表示言語（日本語・英語）

2026-10-07 追加。アプリの表示を日本語と英語で切り替えられる。

## 仕組み

- コードに書くのは日本語のまま。日本語の文がそのまま翻訳のキーになる（別のキー名は作らない）。
  - C#：`L.T("日本語")`、差し込みがあるときは `L.F("{0}本を解析しました", count)`（`$"…"` は使わない）。
  - XAML：`Text="{l:T '日本語'}"`、書式付きのバインディングは `{l:TBinding Count, TFormat={}{0}件}`（`xmlns:l="clr-namespace:LocalMediaAI.App.Localization"`）。
- 英語は `src/LocalMediaAI.Core/Localization/en.json`（日本語 → 英語）。埋め込みリソースとしてアプリに入る。訳がない文は日本語のまま表示される。
- 言語は起動時に1回だけ決まる（`L.Use`）。変更は次の起動から反映。設定はデータフォルダーの `ui-language.txt`（`ja` / `en`）。カタログより前に読む必要があるので、DB ではなくファイルにしている。
- 初回起動時（`ui-language.txt` がないとき）は、ウィンドウを出す前に言語選択画面を出す。選ばずに閉じたら Windows の言語で起動し、次回もう一度尋ねる。
- 設定画面のいちばん上に「表示言語」。言語名（日本語 / English）は、どちらの言語のときもそのまま表示する。

## 翻訳しないもの

- タグの定義（`Tagging.cs`）：「屋内の場面が映っている」などは日本語 CLIP モデルへの入力。タグ名は DB に日本語で保存し、表示するときに訳す（`TagReviewRow.DisplayName`）。
- ファイル名・フォルダー名・パスなどユーザーのデータ。
- 両方の言語で見せる文言（初回の言語選択画面、設定の言語名）：行に `// i18n: keep` を付ける。
- 静的フィールドで一度だけ作る文言は、言語を決める前に固定されてしまうので、プロパティ（`=>`）にする。

## 文言を追加・変更するとき

1. コードに日本語で `L.T` / `L.F` / `{l:T '…'}` を書く（既存の日本語の文字列を一括で包むときは `python tools/i18n/wrap_csharp.py <フォルダー>` と `wrap_xaml.py`。何度実行しても同じ結果になる）。
2. `python tools/i18n/extract.py` で未翻訳を確認し、`en.json` に英語を足す（`--missing <file>` で一覧を書き出せる）。
3. テストで確認：
   - `LocalizationCatalogTests`：すべての文に英訳がある・`{0}` などの差し込みが一致する・英語の書式が `string.Format` で使える・英訳に日本語が残っていない。
   - `EnglishUiTests`：英語で各画面（整理画面・設定・ライブラリ・AI検索・レビュー・ファイル操作）を描画し、画面に日本語が残っていないことを確かめる。画像は `artifacts/ui-english/` に出る。言語はアプリ全体の設定なので、このテストは他と並列に動かさない。

訳語の対訳表は最初の翻訳時に作った（整理リスト = cleanup list、このまま残す = Keep as is、完全に同じ = Identical、よく似ている = Very similar など）。新しい文もこれに合わせる。
